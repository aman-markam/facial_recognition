# Legacy Scripts & Standalone Tools

This folder contains legacy scripts from earlier standalone OpenCV/Tkinter iterations of the project.

Production code is located under `app/` and root configuration files (`main.py`, `face_engine.py`, `database.py`, `alembic/`).

Files archived here:
- `app.py`: Legacy Tkinter GUI app.
- `attendance.py`: Legacy OpenCV face attendance script.
- `face_capture.py`: Legacy dataset capture script.
- `trainer.py`: Legacy LBPH trainer.
- `haarcascade_frontalface_default.xml`: Haar cascade XML.
- `migrate_to_postgres.py`: Legacy migration utility.
